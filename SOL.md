# Motion OS

The product is a local-first video editor. Humans and agents operate one versioned timeline through validated commands. The editor, real media, playback and correct exports take priority over dashboards or SaaS infrastructure.

Authoritative current direction: the owner's master engineering prompt received 1 October 2026. Architecture and migration evidence: [editor audit](docs/EDITOR_AUDIT_AND_MIGRATION.md). Older `.agents` plans are references; conflicts resolve in favor of the owner's latest instructions.

Preserve original media and immutable revisions. Bind local services to loopback. Keep credentials out of browser code and source control. Scope assets and instructions to their project/brand. Never execute generated code or third-party skills in the ordinary editing pipeline. Significant agent edits are proposals for user approval. Never report mocks as functioning integrations.

Initial milestones: audit; functioning editor; accurate rendering; built-in Director; local MCP; advanced motion; governed skill improvements; commercial readiness. See the audit for acceptance gates and known limitations.
